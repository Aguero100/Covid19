# Прогнозирование смертельного исхода от COVID-19

Учебный проект по построению модели машинного обучения для прогнозирования смертельного исхода у пациентов с COVID-19 на основе анонимизированных клинических данных.

## Задача:
Построить модель бинарной классификации, предсказывающую смерть пациента (признак DEATH) по набору клинических и демографических признаков. Исходный набор данных содержит 1 048 575 записей и 21 признак; логические значения закодированы как 1 («да») и 2 («нет»), пропуски обозначены значениями 97 и 99.

## Что сделано:
Загружен и изучен набор данных Covid Data.csv (1 048 575 строк, 21 столбец). Выполнена предварительная обработка: удалены строки с пропущенными значениями (97/99) в признаках, столбец DATE_DIED преобразован в бинарный целевой признак DEATH (1 — умер, 2 — жив), удалены столбцы INTUBED и ICU из-за большого количества пропусков.

Проведён отбор признаков: удалены признаки с низкой корреляцией с целевой переменной (SEX, PREGNANT, COPD, ASTHMA, INMSUPR, OTHER_DISEASE, CARDIOVASCULAR, OBESITY, TOBACCO). Категориальные признаки MEDICAL_UNIT и CLASIFFICATION_FINAL закодированы через one-hot encoding, числовой признак AGE масштабирован с помощью RobustScaler.

Выполнен разведочный анализ данных: построены распределения целевой переменной, возраста, пола, наличия сопутствующих заболеваний (ожирение, пневмония, гипертония), а также корреляционная матрица признаков.

Выявлен дисбаланс классов: доля смертей составляет около 7,3%. Для борьбы с дисбалансом применён метод недостаточной выборки (RandomUnderSampler), что позволило уравнять классы (по 74 657 наблюдений).

Обучена модель логистической регрессии; оценка качества проводилась на отложенной тестовой выборке (20%). Рассчитаны метрики accuracy, F1-score по классам, построены матрица ошибок и ROC-кривая.

## Стек технологий
Python 3.9+, pandas, numpy, matplotlib, seaborn, scikit-learn, imbalanced-learn. Среда разработки — Jupyter Notebook.

## Ключевые результаты:
Исходная модель логистической регрессии на несбалансированной выборке показала accuracy 0.939, 
однако F1-score для класса «умер» составил всего 0.52, что указывает на плохое распознавание миноритарного класса. 
После применения недостаточной выборки (RandomUnderSampler) accuracy составила 0.905, а F1-score выровнялся и достиг 0.906 для класса «умер» и 0.904 для класса «жив». 
Матрица ошибок подтверждает сбалансированное качество предсказаний. ROC-кривая демонстрирует хорошую разделяющую способность модели.
